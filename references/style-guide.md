# 风格指南 · 百图斩通用风格拆解框架

「百图斩」是**风格无关**的复刻技能：任何视觉风格都可以「斩」成一份可复用的风格档案。来图识别的深度决定一切——锚定段的每个词都必须来自对参考图的实证观察。本文件规定六件事：

1. **来图识别 SOP**（溯源识人 → 明度基调判定 → 逐区域放大目检 → 骨架/可变特征分离）
2. **锚定段写作规范**（五个必备句 + 负面约束按参考图反推）
3. **通用负面约束**与**场景转译速查表**（含场景贴上下文要求）
4. **系列一致性**（同一套图 = 同一世界）
5. **样张核验闭环**（出 1 张 → 对图核验 → 全绿才批量，含场景-明度兼容规则）
6. **新风格建档流程**与 `styles/<name>.md` 文件格式

内置示例档案见 `styles/watercolor-sketch.md`，参考图 `assets/example-watercolor-sketch.jpeg`。

## 一、来图识别 SOP（斩风格 · 三步，缺一不可）

来图识别是百图斩的命门：**锚定段的每一个词都必须来自对参考图的实证观察，禁止凭风格名词套模板**。按以下三步走：

### 第 0 步：溯源识人（这是谁画的？属于哪个风格谱系？）

拿到参考图先做**溯源**，再拆风格：

1. **识人**：凭视觉签名（媒介、版式、手法）+ 联网搜索，判断这张图最可能的作者/工作室/流派，并标注置信度（**确认 / 高置信 / 未知**）。搜索用图中可见文字 + 题材 + 媒介作关键词（例：报头文字 + 人物名 + "watercolor caricature"）。
2. **查谱系**：若识别出作者，去查他的**整体作品**而非只看这一张——这个作者/流派贯穿所有作品的通用特征是什么？（例：Barry Blitt = 《纽约客》御用讽刺漫画家 → "钢笔淡彩 + 漫画式夸张 + 报刊版面叙事"是他所有作品的共性。）**通用特征从谱系来，不只从单张图来**——这保证档案换个题材依然成立。
3. **通用化校验**：把观察到的特征分成两列——
   - **内容特征**（只对这张图成立：具体报头名、具体人物、具体事件）→ **禁止进档案**；
   - **通用特征**（媒介、明度、线条、色板、夸张度、版式语言）→ 进档案。
4. **名字纪律**：作者名只用于研究与档案里的「溯源」记录，**严禁写进锚定段和提示词**（触发出图工具版权审核，实测 HTTP 403；风格锁定靠通用描述 + 参考图）。
5. 溯源失败（未知作者）不阻塞流程：直接以"佚名 + 流派判断"（如"日系扁平插画""像素艺术"）进入第 1 步，谱系一栏标注"未知"。

### 第 1 步：明度基调判定（风格的第一指纹）

先看整张图回答一个问题：**这张图的明度基调是高调、中间调还是低调？**

判定不能只靠肉眼感觉，必须**脚本实测量化指纹**并写进档案（可复核）：

- **明度分布**：暗部(<80)/中间(80–180)/亮部(≥180)三段占比 + 中位数——例：亮部 84% = 极端高调；亮部仅 8% = 中间调偏暗；
- **饱和度**：中位数与 p90——决定色板写法是"淡了三分"还是"局部极艳"；
- **主色板**：量化提取前 5–8 色（HEX + 占比），标注各自角色（墨线/底色/点缀）。

**多张参考图时跨图互证**：每张各跑一次指纹，**只有各图都成立的不变量才算风格骨架**（例：三图均为"单主体 + 纯色平涂背景占 4–7 成 + 近零暗部"）；各图互异的维度（如背景具体色相）是变量，进场景段不进锚定段。

- **高调（high-key）**：大面积白纸/浅色，无深色阴影，无戏剧性光源（如内置示例 `editorial-ink-wash` 的参考图）
- **中间调**：明暗均衡，有明确光影但不过戏剧化
- **低调（low-key）**：大面积深色、强明暗对比、戏剧性光

明度基调错，整张图必然跑偏（实测教训：把高调参考图写成"交叉排线表现阴影"，出图全部变成素描感暗黑插画）。**判定结果必须写进档案，并且作为场景筛选的硬约束（见第 6 条）。**

### 第 2 步：逐区域放大目检（不许只看缩略图）

把参考图切 3–5 个区域放大看细节，至少覆盖：①主体（人物面部/核心物件）②线条最密处 ③色块边缘 ④背景/留白处 ⑤角落细节。每个维度写结论时必须带**证据**——"在图中哪个位置看到的"。

| 维度 | 要回答的问题 | 观察要点（放大后核实） | 证据示例 |
|------|--------------|------------------------|----------|
| 明度基调 | 高/中/低调？ | 画面最深色有多深？阴影面积占比？ | "全图最深是领带的藏蓝，无黑色块" |
| 媒介 | 用什么"画"的？ | 铅笔/钢笔/马克笔/水彩/板绘……纸本还是数字 | "线条有针管笔起笔顿挫" |
| 线条 | 线条的性格与**密度**？ | 粗细（发丝级/常规/粗）、闭合与否、**排线密度**（几乎不排线/局部排线/满幅排线） | "阴影仅 3–5 根发线，无交叉排线" |
| 上色方式 | 颜色怎么上的、**叠几层**？ | 平涂/罩染/厚涂；每个色块层数（一两层/多层）；边缘软硬 | "肤色仅一层薄色+局部腮红" |
| 色板 | 主色哪几个、明度多高？ | 列 5–8 个具体色名；饱和度与明度倾向 | "浅桃、淡米黄、浅青灰，整体明度>70%" |
| 构图 | 镜头感与留白？ | 视角、景别、**留白比例**（约几成） | "白纸留白超过 50%" |
| 质感 | 表面与气质？ | 纸纹/噪点/光滑；气质关键词 3–5 个 | "可见水彩晕斑和水痕" |
| 夸张度 | 写实还是变形？ | 比例（写实/温和夸张/强漫画）、五官处理 | "头部占比约 1/3，漫画式夸张" |
| 题材倾向 | 擅长画什么？ | 人物/风景/器物/场景 | — |
| 画幅 | 默认比例？ | 横版/方形/竖版 | — |

### 第 3 步：区分骨架特征与可变特征

- **骨架特征**（进锚定段，逐字复用）：明度基调、线条粗细与排线密度、色块层数、色板、留白比例、夸张度、质感。
- **可变特征**（进场景段，每图可换）：题材、人物、动作、具体构图。

把骨架特征误判为可变（或反过来）是跑偏的第二大根源。

## 二、锚定段写作规范

锚定段是风格的"压缩包"，出图时**逐字复用**。除了原来的一般要求，锚定段必须包含以下**五个必备句**，缺一句就是不合格档案：

1. **明度基调句**：开门见山写死高调/中间调/低调。例：高调写 `High-key ..., bright and airy`；低调写 `Low-key ..., moody and dark`。
2. **线条定量句**：粗细 + 排线密度写具体。例：`Delicate hairline-thin wiry black pen outlines; shading is only hinted at with a few sparse hairline strokes, never filled in.`（禁止只写"cross-hatching"这种会诱发满幅排线的词）
3. **色块层数句**：例：`only one or two thin tones per shape, visible water blotches, large areas of untouched white paper`。
4. **负向形态句**：写清"这风格**不是什么**"，从参考图里**看不到的东西**反推。例：参考图无深色阴影 → `No dark shadows anywhere, no dramatic lighting, no tonal modeling.` 这句与负面约束呼应，放在锚定段内是因为很多出图工具不看 negative 参数。
5. **签名禁令句**：`no readable artist signature and no dates or timestamps anywhere in the image`。

其他要求不变：

- **英文锚定段**（主 prompt 前缀）：80–150 词，含 `{ratio}` 占位符；**中文锚定段**为对应中译。
- **严禁出现真实画师姓名**（触发出图工具版权审核，实测 HTTP 403）；用通用描述 + 参考图锁风格。
- 只写**骨架特征**；题材、人物、动作属于场景段，不进锚定段。

**负面约束也要按参考图反推**：在通用清单基础上，把"参考图里看不到的东西"逐条加进去。例：高调淡彩参考图看不到排线、深色、戏剧光 → 追加 `no dense cross-hatching, no dark shadows, no dramatic lighting, no chiaroscuro, no graphic-novel shading, no moody darkness`。

## 三、通用负面约束（每次必带）

英文（出图工具负面词）：

```
no photorealism, no photography, no 3D render, no CGI, no digital smooth gradients,
no anime or manga style, no oil painting, no thick impasto, no neon colors,
no sharp vector lines, no flat cartoon fill,
no artist signature, no readable signature, no dates, no timestamps, no watermark
```

中文（中文工具同样适用）：

```
不要照片写实、不要摄影感、不要 3D 渲染、不要数码平滑渐变、
不要动漫风、不要厚涂油画、不要霓虹色、不要矢量锐线、不要平涂卡通、
不要画师签名、不要日期时间、不要水印
```

建档时可按风格增删（例如像素风档案应去掉 "no sharp vector lines" 并加 "no anti-aliased smooth edges"），但**签名/日期/时间/水印四条永远保留**。

## 四、场景描述写法与抽象概念转译速查

锚定段之后接场景段，只写变量：人物 + 动作 + 环境 + 氛围，英文 1–3 句。任何题材都可以，只要写成"现场的人在做具体的事"。避免罗列风格词（风格已在锚定段）。

**场景必须贴上下文**：每个场景从原文摘 1–2 句作为依据（记录在提示词清单里），场景段中的细节（时间、年龄、物件、数量、情绪）必须能与原文对上，不编造与原文矛盾的信息（例：原文"花了两千块钱布置"，画面里就不要出现"RENT 950"这类凭空细节）。

| 文章主题 | 场景化写法示例 |
|----------|----------------|
| 庭审/法律事件 | 证人席、律师陈词、旁听席反应、证据展示屏 |
| 公司/商业新闻 | 会议室对峙、发布会讲台、深夜办公室、签约握手 |
| 财经/市场 | 交易屏前的交易员、公告栏前围观人群、摔落的文件 |
| 科技/产品 | 发布会舞台、工程师围在白板前、实验室操作台 |
| 社会/纪实 | 街头采访、排队人群、当事人背影与记者话筒 |
| 文化/生活 | 市集摊位、咖啡馆长谈、书店角落阅读的人 |
| 人物特写稿 | 当事人侧脸近景 + 背景氛围，手边标志性物件 |
| 数据/观点 | 比喻场景：天平、空椅子、长桌两端的人 |

## 四点五、系列一致性（同一套图 = 同一世界）

一套配图（一篇文章的 2–4 张）除了共享风格锚定段，还必须共享两条**系列锚定**，逐字复用：

1. **角色锚定**（`--character`）：一句话锁定主角外貌与穿着，每张图原样带上。例：
   `a lean Chinese male artist in his late twenties, short slightly messy black hair, gentle tired eyes, wearing a dark slate-blue long-sleeve shirt`
   没有固定主角的文章（如财经群像）可省略；有主角的人物稿**必须**使用。
2. **情绪光线锚定**：在每条场景段末尾固定一句统一的光线与情绪基调（如 `quiet contemplative mood, soft muted daylight`），避免一套图里一张浓墨重彩一张清新明亮。
3. **文字策略二选一并全批统一**：
   - 要标注字 → 每张都带 `Caption:` 手写标注（风格允许时）；
   - 不要文字 → 每张都加 `--no-text`（贴合中文文章场景，避免画面蹦出英文海报字）。
   混用会破坏系列感。
4. 出图后逐张目检：主角长相是否连贯、色温情绪是否统一、场景细节是否与原文矛盾。任一不达标，收紧对应锚定重生成该张。

## 五、样张核验闭环（出 1 张 → 对图核验 → 通过才批量）

新档案或重要任务必须先出**样张**并走完核验闭环，禁止直接批量出图：

1. 用新锚定段出 1 张样张（选最简单的场景）。
2. **对图核验**：把样张与参考图并排，按 `references/style-audit-checklist.md` 逐项对照——明度基调、线条密度、色块层数、留白比例、夸张度、质感、有无文字/签名。每项判定 一致 / 偏一点 / 跑偏，并写明偏在哪。
3. 任一项"跑偏" → 回修锚定段对应句（明度偏暗就加强明度基调句与负向形态句，排线过密就收紧线条定量句），重出样张。**核验全绿之前不批量。**
4. 批量出图后，每张仍按清单快速目检。

**场景-明度兼容规则（硬约束）**：场景描述不得与明度基调打架。高调档案不选"深夜、一盏孤灯、暗房"这类强制暗调的场景，改选同内容的白天/均匀光版本（实测教训：高调淡彩档案配"深夜台灯"场景，出图必然变成强明暗对比）；低调档案反之。若文章关键场景天生是夜晚，用"窗外天光/明亮室内灯"等方式改写成与基调兼容的画面，并在提示词清单里注明改写理由。

**场景-形态兼容规则（硬约束）**：场景描述不得与档案的构图形态打架。**场景型风格**（有环境、有透视，如 `ligne-claire`、`watercolor-sketch`）可以画叙事场面；**单主体型风格**（纯色背景、无环境无透视，如 `naive-crayon`）**禁止写房间、街景、人群叙事**，必须把每个文章场景提炼成**一个象征物或一个小组合**（大狗+小球、画架+笔桶、手+蝴蝶），并在每张之间设计背景色节奏。判断依据来自档案拆解表的"构图"行：参考图有环境 → 场景型；参考图是纯色背景单主体 → 单主体型。

## 六、新风格建档流程（斩风格 SOP）

1. 收参考图 1–3 张，复制进 `assets/`，命名与档案对应（如 `assets/example-<风格英文名>.jpeg`）。
2. 按第一节 SOP 做**来图识别**：先做溯源识人（作者/流派 + 置信度 + 风格谱系 + 通用化校验），再判明度基调，再逐区域放大目检填拆解表（每维度带证据），最后区分骨架/可变特征。
3. 按第二节规范写**英文锚定段**与**中文锚定段**——五个必备句齐全（明度基调句 / 线条定量句 / 色块层数句 / 负向形态句 / 签名禁令句），含 `{ratio}` 占位符，无真实画师姓名。
4. 写**负面约束清单**：通用清单 + 按参考图反推的"参考图里看不到的东西"；签名/日期/时间/水印四条永远保留。
5. 写**抽象概念→场景转译建议**（3–6 条，贴合该风格擅长题材与明度基调）与**默认画幅**。
6. 落盘为 `styles/<风格英文名>.md`（小写、连字符），格式见下。
7. 按第五节走**样张核验闭环**：出 1 张样张 → 按 `references/style-audit-checklist.md` 对图核验 → 全绿后档案才算建成；跑偏回修锚定段与负面约束重出，直到稳定。

### `styles/<name>.md` 文件格式（脚本解析契约）

普通 Markdown，自由撰写拆解表与说明，但**必须包含三个带语言标记的代码块**，`scripts/build_prompt.py` 用正则提取：

````markdown
```anchor-en
（英文锚定段，可含 {ratio} 占位符）
```

```anchor-cn
（中文锚定段，可含 {ratio} 占位符）
```

```negative
（英文负面约束，逗号分隔）
```
````

缺失任一代码块或文件不存在时，脚本会报错并提示 `--list-styles`。
