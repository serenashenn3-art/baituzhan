# 风格档案 · watercolor-sketch（水彩速写 · 新闻纪实）

> 内置示例风格档案。参考图：`assets/example-watercolor-sketch.jpeg`
> 建档依据：1 张参考图 · 由「百图斩」斩风格流程产出

## 风格拆解表

| 维度 | 特征 |
|------|------|
| 媒介 | 钢笔/针管笔墨水勾线 + 水彩湿画法薄涂，纸本 |
| 线条 | 松动、快速、手绘速写感；轮廓线不完全闭合；有重复试探线 |
| 上色方式 | 透明水彩罩染，色层薄、可见纸纹；边缘自然洇开 |
| 色板 | 淡黄、粉紫、薰衣草紫、天蓝、木色棕、暖粉肤色、灰绿点缀 |
| 构图 | 旁观者/现场记者视角，中远景群像或近景人物，有前后纵深 |
| 质感 | 纸纹可见、手绘温度、新闻纪实质感 |
| 题材倾向 | 不限：庭审、商务、科技、财经、社会、文化、人物、事件现场 |
| 默认画幅 | 横版 16:9，也可 3:2 |

补充：背景为大面积单色水彩晕染 + 大量留白；可有手写体场景标注（**不含画师签名、日期、时间**）。

## 负面约束清单（每次必带）

```negative
no photorealism, no photography, no 3D render, no CGI, no digital smooth gradients,
no anime or manga style, no oil painting, no thick impasto, no neon colors,
no sharp vector lines, no flat cartoon fill,
no artist signature, no readable signature, no dates, no timestamps, no watermark
```

## 抽象概念 → 场景转译建议

- 冲突/对立 → 长桌两端的人、对峙的双方、旁观者反应
- 趋势/数据 → 比喻场景：天平、空椅子、人群朝向
- 人物特写 → 侧脸近景 + 背景晕染 + 手边标志性物件

## 默认画幅

横版 `{ratio}` 默认 16:9（公众号头图），可切换 3:2。
